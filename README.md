# Lox

> 一个以“盒子”为核心的三维激光解谜游戏，本科三年级“计算机图形学”课程设计。

## 简介

《Lox》的主角是一个正方体“盒子”。盒子有透明亚克力外壳和不透明塑料内胆，六个面各是一个逻辑二维、渲染三维的子谜题。玩家通过旋转盒子、移动和旋转内部的光学器件，把激光引导到对应颜色的接收器，满足六种全局颜色（M/Y/G/B/C/R）的需求，最后点击顶锁上的 `TOUCH` 通关；钥匙孔动画待补。

## 当前实现状态

已实现：

- Tuanjie `2022.3.62t18` 工程、`Main.unity` 场景和 Windows x86_64 构建。
- 无色透明亚克力外壳（`Lox/AcrylicGlass`，运行时生成内层壳以表现壁厚）、带圆角和圆棱的磨砂铝合金包边（`Lox/FrostedAluminum`）、`#bbbbbb` 缎面磨砂玻璃内胆、六个 `FaceRoot`。
- 24 段边界墙（`#777777`）；固定墙和镜面由关卡 JSON 生成；内胆和所有墙使用 `Lox/SatinFrostedGlass` 缎面磨砂玻璃材质（较大颗粒磨砂）。
- 14 个发射器、10 个接收器、1 个三棱镜、6 个滤光片、4 面可操作平面镜、顶面总锁底座、6 盏环灯和 1 盏中心白灯。
- 鼠标点选、`#ffff77` 二维轮廓描边、按受限轴移动、绕面法线旋转。
- 盒子鼠标拖动 + 自动吸附，以及小键盘整体旋转。
- 简化的 2D 激光：接收器（墙面半圆柱、角落 1/4 圆柱、自由摆放完整圆柱）、平面镜/凹面镜反射、墙体阻挡、柱面凸透镜折射、三棱镜分光。
- 三棱镜：等边三角直棱柱；复合光进入时按 R/G/B 分量拆成独立分支，每个分量使用独立折射率并支持全反射。
- 颜色核心：16 色调色板、RGB 分量混色、亮度不敏感的接收器匹配；支持多束光进入同一接收器。
- 滤光片仿真：按分量吸收，命中极窄端时阻断光线；光束按段使用滤光后的颜色渲染；光路带有轻微的加法软边光晕。
- 滤光片、透镜与三棱镜统一使用外壳的 `Lox/AcrylicGlass` 亚克力材质：透明、带菲涅耳与边缘高光；滤光片保留各自的 C/M/Y/G 颜色，三棱镜使用更清澈的专用 `Prism_Acrylic` 实例。
- 激光光路带有轻微光晕；指示灯的光晕效果仍待调优（当前很弱，不会穿透遮挡）。
- 锁核心：覆盖器件、阻断光线、按全局颜色解锁、开盖与筒壁下沉；锁体、锁盖和总锁底座使用缎面磨砂玻璃材质；小型锁顶部用所需颜色球冠指示灯，总锁保持环形灯；两者都是接收器未激活时灯亮、激活后熄灭；指示灯球冠底面半径 = 所属锁半径的 1/5，顶面总锁半径 = 内胆边长的 1/4；解锁条件来自 JSON。
- bottom 面（青面）调色台：3 个可移动/可旋转白色发射器、中心可旋转三棱镜（Y+M 锁）、顶部 C/M/Y 滤光片、底部 `B+Y` / `R+C` 两个局部接收器，以及两者正中间的红色全局接收器（绑定顶面 R 灯）；M 滤光片保留。
- back 面“3 段墙 + 底部固定平面镜 + 顶部可左右移动平面镜 + 可上下移动凹面镜”关卡，绿色接收器位于墙面 L 形交角；left 面“三发射器 + 自由移动凸透镜”关卡（凸透镜带绿色锁）。
- right 面（黄面）关卡：左侧白色光源、G+B 解锁的顶部白色光源、右下角青色光源、45° 橄榄透镜、两段斜墙、绿色/黄色滤光片、`G+C` 接收器、`G+C` 锁覆盖的黄色接收器。
- top 面正方形反射环：白色发射器（B+Y 锁）、R+C 锁的对角镜、M/C 锁的两面角镜、白色接收器和总锁中心白灯；全部锁打开后白光绕环回到接收器。
- 完整关卡 JSON 几何加载器：`Assets/StreamingAssets/Levels/level_01.json` 描述器件类型/颜色/位置/尺寸/可操作性、固定墙体、平面镜、凹面镜和顶面总锁；启动时由 `DeviceConfigLoader` 生成。
- 左下角 IMGUI 键位提示，粗体文字、较大行距，使用 `Assets/Resources/Icons/` 下的 PNG 图标；鼠标左键项始终显示，选中后按器件是否可平移/旋转追加对应提示。
- 右上角计时器（粗体微软雅黑，`#999999`）、左上角仅图标无外框的“重新开始”按钮（`Restart.png`），以及通关后的顶锁 `TOUCH` 和“你赢了！”对话框；计时在首次鼠标/键盘按下时开始，总锁所有指示灯熄灭后停止。

当前初始状态：

- 初始视角正对顶面（总锁的 6 盏环灯与中心白灯）。
- front（M/C）有红、蓝、白三个固定发射器：红、蓝两束光由自由移动的柱面透镜聚焦，在洋红接收器处混成 M；白光经青色滤光片后，由同一块透镜折射到左下角的青色接收器。透镜被绿色（G）锁覆盖，需要先点亮 back 面的 G；该面初始不亮，M/C 灯亮着。
- back（G）被墙面 1 挡住，需要转动绿色发射器，经底部固定平面镜、右侧凹面镜和顶部可移动平面镜，把光送入 L 形墙角的绿色接收器。
- left（B）有青、蓝、红三个固定发射器，全部朝向蓝色接收器；凸透镜初始居中且被绿色锁覆盖，解锁后可自由移动和旋转，用来让只有蓝光进入接收器。
- right（Y）的黄色接收器被 `G+C` 锁覆盖；左侧白色光源经黄色滤光片后变黄，顶部白色光源被 G+B 锁住，因此 Y 初始不亮。G+B 解锁后，调整顶部光源/透镜让绿色光束与右下角青色光源在 `G+C` 接收器会合，才能解锁 Y。
- bottom（青面）有三个白色发射器、中心三棱镜（被 Y+M 锁覆盖）和三块滤光片；`B+Y` / `R+C` 局部接收器初始都不亮；中间的红色全局接收器初始也不亮，顶面 R 灯亮着。
- top（总锁面）有正方形反射环：白色发射器、三面平面镜和白色接收器；四把锁（B+Y、R+C、M、C）全部打开后，白光绕环进入接收器，总锁中心白灯熄灭。
- 顶面总锁固定 M/Y/G/B/C/R 六盏灯和中心白灯；总锁所有指示灯熄灭后，总锁中心出现 `TOUCH`，点击后弹出“你赢了！”对话框并显示最终用时；钥匙孔动画尚未实现。

## 核心玩法

- 旋转盒子，观察六个面。
- 点选发射器、接收器、平面镜、凹面镜、凸透镜、三棱镜等器件。
- 选中后沿允许的轴移动，或绕面法线旋转。
- 让激光进入对应颜色的接收器，使顶面同色需求灯熄灭。
- 某些器件的可移动/可旋转属性及范围由关卡 JSON 决定。
- 锁覆盖与颜色解锁已实现；总锁所有指示灯熄灭后顶锁出现 `TOUCH`，点击进入通关对话框；钥匙孔动画未实现。

## 初版特征

1. 盒子外壳与内胆结构完整。
2. 每个面至少有一个发射器和一个接收器，并可放置额外的器件/墙体。
3. 主要光学器件包括：滤光片、平面镜、凸面镜、凹面镜、凸透镜、三棱镜。玻璃砖已删除，不再实现。
4. 初版使用简单材质和彩色激光线，不使用 PBR。
5. 鼠标点选器件；选中后沿允许轴平移，旋转只绕子谜题面法线；禁止旋转由关卡 JSON 控制。
6. 鼠标拖动旋转盒子并自动吸附；小键盘可整体旋转；摄像机固定。

## 终版特征

1. 满足初版全部基础条件。
2. 所有元素拥有独立材质。
3. 关卡由 JSON 描述，游戏运行时加载。
4. 更完整的光学表现、材质、动画和关卡内容。

## 操作

| 操作 | 输入 |
| --- | --- |
| 旋转盒子 | 鼠标左键拖动空白处 |
| 整体旋转 x / x' | 小键盘 8 / 2 |
| 整体旋转 y' / y | 小键盘 4 / 6 |
| 整体旋转 z' / z | 小键盘 1 / 3 |
| 选择器件 | 鼠标左键点击器件 |
| 选中效果 | 器件在当前视图下的二维轮廓描边（#ffff77，约 3px） |
| 取消选择 | 单击空白处，或开始拖动盒子 |
| 平移选中器件 | `A`/`D` 屏幕左/右，`W`/`S` 屏幕下/上，投影到器件唯一可移动的轴 |
| 旋转选中器件 | ← / →（仅限允许旋转的器件） |
| 开始计时 | 进入游戏或重开后第一次鼠标按下 / 键盘按下 |
| 重新开始 | 左上角仅图标按钮；通关对话框的“确定”效果相同 |
| 全屏 / 窗口切换 | `F11` 或 `Alt+Enter`；窗口模式下可拖动边缘缩放或最大化 |

> 盒子和器件的移动/旋转方向以摄像机参考系为准。数字键盘旋转当前使用摄像机右/上/前轴。
> 平移/旋转按键刚按下时只执行一个与连续帧相同的步长；持续按住 0.5 秒后才开始连续操作。旋转速度为 45°/s。
> 蓝色面透镜解锁后是自由移动器件，`A/D/W/S` 可在面内两轴移动。
> 拖动盒子旋转时取消当前选中的器件。

> 器件的类型、颜色、位置、尺寸、“是否可移动/可旋转”和范围由 `Assets/StreamingAssets/Levels/level_01.json` 配置；选中、描边、输入和范围夹紧逻辑在 C# 中。

> `R` 重置视角、`Ctrl+R` 重新开始关卡目前尚未实现；重新开始请使用左上角按钮或通关对话框的“确定”。

> 调试：任意时刻连续输入 `↑↑↓↓←→←→BABA` 可熄灭总锁的所有灯（含中心白灯），并直接进入可通关状态，显示 `TOUCH`；重新开始后恢复。

## 技术栈

- Tuanjie（团结引擎）`2022.3.62t18`，编辑器路径：
  `C:\Program Files\Tuanjie\Hub\Editor\2022.3.62t18\Editor\Tuanjie.exe`

## 快速开始

1. 打开 Tuanjie Hub，使用“添加 / 打开项目”选择项目根目录。
2. 等待首次导入完成。
3. 打开 `Assets/Scenes/Main.unity`。
4. 点击 Play。
5. 左下角会显示键位提示；初始视角正对 back（G）面。

> 场景中保留盒子、六个面、边界墙和加载器；各面的器件、固定墙、镜子和总锁灯会在 Play 后由 JSON 生成，因此编辑状态下这些面看起来是空的。

## 构建

界面构建：

1. 在 Tuanjie 中打开 `File → Build Settings`。
2. 平台选择 `Windows`（x86_64）。
3. 点击 `Build`，选择输出目录。

命令行构建：

```powershell
& "C:\Program Files\Tuanjie\Hub\Editor\2022.3.62t18\Editor\Tuanjie.exe" `
  -batchmode -quit `
  -projectPath "<项目根目录>" `
  -buildWindows64Player "<项目根目录>\Build\Lox.exe" `
  -logFile "<日志路径>"
```

注意：

- 同一个工程不能被两个 Tuanjie 实例同时打开。构建前请关闭已打开该工程的编辑器。
- 构建产物 `Build/` 已被 `.gitignore` 忽略。
- 运行 `Lox.exe` 时，`Lox_Data/`、`TuanjiePlayer.dll` 等文件需与它位于同一目录。

## 关卡数据

当前 `level_01.json` 描述**整关的可变几何**，启动时由 `DeviceConfigLoader` 生成：

- `devices`：39 个器件
  - `id`、`type`（`emitter` / `receiver` / `cylindrical_lens` / `filter` / `mirror` / `prism` / `concave_mirror`）、`face`、`color`
  - `position`：面内 `(x, y, z)`（器件平面当前为 `z = 0.05`）
  - `mountPivot`：可选；接收器贴墙点/墙角点相对 `position` 的偏移；用于 L 形墙角的 1/4 接收器
  - `rotation`：初始绕面法线角度（度）
  - `aim`：可选；发射器初始出射方向，缺省按面中心向外推导
  - `size`：本地缩放（发射器约 `0.033`，接收器直径/深度约 `0.066` 等）
  - `castShadows`：是否投影
  - `movable` / `moveMin` / `moveMax`、`freeMove`（2D 自由平移）、`rotatable` / `rotationMin` / `rotationMax`
  - `unlockRequires`：可选；被锁器件需要的全局颜色 ID 列表（如 `["G", "B"]`）
  - `lamp`：接收器绑定的顶面灯颜色（局部颜色接收器如 `G+C` 省略）
  - `focalLength` / `aperture`：柱面透镜参数
  - `radius` / `aperture` / `thickness`：凹面镜曲率、开口和镜片厚度（视觉深度取 `size.z`）
  - `iorR` / `iorG` / `iorB`：可选；三棱镜 R/G/B 分量的折射率，缺省 `1.42 / 1.52 / 1.62`
- `walls`：固定墙（back 3 段、right 两段斜墙）的位置/旋转/尺寸
- `mirrors`：back 固定平面镜的位置/旋转/尺寸；可移动平面镜和凹面镜作为 `devices` 中的 `mirror` / `concave_mirror` 条目
- `goal`：顶面总锁底座半径/高度、灯环半径、灯尺寸和六盏灯的顺序

边界墙（24 段）仍由场景自动生成；器件尺寸、固定墙和镜面不再写在 `Main.unity` 里。材质与透镜网格由 `Assets/Resources/LevelAssets.asset` 提供。

字段定义和校验规则见 `IMPLEMENTATION.md`。
